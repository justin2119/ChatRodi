## 💼 À propos du Projet

**ChatRodi** est une application mobile de chat IA reposant sur le paradigme **Bring Your Own Key (BYOK)**. Elle permet une interaction sécurisée avec l'API **RodiumAi** (`api.rodiumai.io/v1`).
